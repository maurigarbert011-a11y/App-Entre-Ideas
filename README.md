## 🚀 Cómo usar

1. Abre [la página web](https://maurigarbert011-a11y.github.io/App-Entre-Ideas/)
2. Haz clic en **"Radio 102.7 FM"** para acceder a la web principal
3. Haz clic en **"En Vivo YouTube"** para ver la transmisión en vivo

## 📝 Requisitos para GitHub Pages

Si deseas hacer cambios:

1. Ve a **Settings** → **Pages**
2. Selecciona **Deploy from a branch**
3. Elige la rama `main` y carpeta `/ (root)`
4. ¡Listo! La página se actualizará automáticamente
